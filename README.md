# OrbiPeak

OrbiPeak is a fast-paced 3D pastel arcade blaster built using **Three.js** and **Tailwind CSS**. It delivers a rich spatial glass UI experience with zero external dependencies or asset requirements.

## Features
- **360° Ranger Avatar Studio:** Fully customizable characters with adjustable outfits, color palettes, and skin tones.
- **Dynamic Biomes & Atmospheres:** Switch between Grass, Ground, Rock, Underwater, and Sky biomes with dynamic day/night lighting.
- **Multiple Camera Perspectives:** Choose from Classic, Action Close, Top-Down, First-Person, Cinematic, and Fixed Swivel modes.
- **Interactive Control Schemes:** Optimized for both touch devices (smartphones/tablets) and desktop keyboards.
- **Synthesized Web Audio:** Full procedural sound effects and dynamic music generation on the fly.
